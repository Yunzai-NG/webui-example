# webui-example

Yunzai NG 面板插件示例包。四枚组件、一个页签、一份 node 侧入口、一份自带样式表、一项配置 ——
挑这几样是因为它们各示范一件写面板插件时会遇到的事，而不是为了凑数。

## 装法

在面板的「面板商店」里找到「面板插件示例」，点安装。它声明了一个依赖（农历用），商店会自动
装上，无须开终端。装不上时农历那一项会自己退回不显示，包的其余部分照常可用。

手动装也可以：把整个目录放进 `plugins/webui/plugins/`，刷新页面即生效。带 node 侧的包
（本包就是）还要重载一次 webui 插件，那一半才会跑起来。

> `plugins/webui/plugins/` 会被「更新 webui」清空。手动装的请自己留一份备份，经商店装的
> 重新装一次即可。

## 它示范了什么

| 东西 | 落点 | 为什么值得看 |
|---|---|---|
| 一个包给出多枚组件 | `index.js` 的 `export default [...]` | 不必为四枚组件做四个包 |
| 插件自加页签 | `index.js` 的 `export const tabs` | 页签占整块内容区，与组件是两种东西 |
| 组件自己的交互 | `widgets/hitokoto.js` 的「换一句」与「复制」 | 取数中 / 成功 / 失败三种状态各有画法；剪贴板在 `http://` 下要退路 |
| 配置改完即生效 | `server/index.js` 每次现调 `ctx.config()` | 不在 setup 里存下来，否则「改了没反应」 |
| 自带计时器要自己收 | `widgets/clock.js` 的 `api.onUnmounted` | 时钟要每秒一拍，而共享节拍是 5 秒 |
| 一枚组件拆成两枚 | `widgets/clock.js` 与 `widgets/calendar.js` | 每秒重画的与一天变一次的不该合成一张卡片 |
| 包带自己的依赖 | `server/index.js` 的 `lunar-typescript` | 依赖只在 node 侧用，且装不上时不塌 |
| node 侧代取外部接口 | `server/index.js` 的一言 | 绕开 CORS，且接口地址只在一处读 |
| 自带一份样式表 | `style.css` + 一言 / 日历 / 时钟 / 跑马灯 | 关键帧、月历网格与伪元素写不进行内样式；类名不必加前缀，动画名必须加 |
| 容器查询而非媒体查询 | `style.css` 的 `@container` | 一格能有多窄取决于它占几列，与窗口宽度无关 |

## 配置项

进「插件」页，在「面板插件示例」这张卡片上点「配置」。

只有一项 —— 组件的样子不做成开关，那些取舍在源码里已经定了：

| 项 | 默认 | 说明 |
|---|---|---|
| 一言接口 | `https://v1.hitokoto.cn` | 换成别家的接口或自建镜像都可以，留空按默认值算。响应里的句子字段认 `hitokoto` / `text` / `content` / `sentence` 四种写法 |

## 四条写的时候容易踩的

**浏览器侧那几个文件里不能出现裸包名。** 面板插件没有构建步骤，`import "lunar-typescript"`
在浏览器里解析不开，而后果不是那一行失效 —— 是整个包连一枚组件都装不上。依赖只能在
`server/` 那一半用。

**自定义类名要么自带样式表、要么用行内样式。** 写一个既不在面板样式表里、本包 `style.css`
里也没有的类名，那一行就是无样式的纯文本，且不报错。面板现成可用的有 `.card`、`.stat`
（`b` 大字 + `span` 说明）、`.hint`、`.err`、`.mono`、`.plain`、`.toolbar`、`.tag`、`.banner`。
自带样式表只有**包**才有（单文件没有 `package.json`），且动画名要自己加前缀 —— 它是全局的。

**配置要每次现取。** `const cfg = api.config.value` 写在 `setup` 里，取到的是那一刻的值，
此后使用者改了配置它不会变 —— 表现为「改了配置没反应」，与「配置没保存上」看起来一样。
要写在渲染函数里。

**node 侧的路由读不到查询串。** `ctx.route(path, handler)` 的 handler 无参，故「取一句」与
「取一批」是两条路径（`hitokoto` 与 `hitokoto/batch`），日期一类的东西由 node 侧自己取。
